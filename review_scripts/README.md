# סקריפטי הסוקרים

אלה הסקריפטים ששלושת הסוקרים בכל סבב כתבו כדי לבדוק את הניתוח (פירוט ב-`verification.md`). הם נשמרים כפי שהורצו, כתיעוד של הבדיקות.

שימו לב: הנתיבים בתוכם מוחלטים, מסביבת העבודה המקורית (`/home/claude/...`). כדי להריץ אותם מחדש, צריך להחליף את הנתיבים לתיקיית `data` ולתיקיית התוצרים המקומית.

| סבב | תיקייה | תפקיד |
|---|---|---|
| ראשון | `numeric/` | שחזור עצמאי של כל המספרים |
| ראשון | `method/` | ביקורת מתודולוגית והנחות |
| ראשון | `stats/` | הסקה סטטיסטית, רעש ורגרסיה לממוצע |
| שני | `round2/factcheck/` | בדיקת עובדות של סיכום הסבב הראשון |
| שני | `round2/devil/` | ערעור על מסקנות הסבב הראשון |
| שני | `round2/sources/` | בדיקת הקפיצה בקליפורניה ובקולורדו מול מקורות ראשוניים |
